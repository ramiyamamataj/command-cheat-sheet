# Command Cheat Sheet

## Linux Commands
* `pwd` - Prints the current working directory.
* `ls` - Lists files and directories in the current folder.
* `cd` - Changes the directory path.
* `mkdir` - Creates a new folder.
* `rm` - Deletes a specified file.
* `cp` - Copies files or directories from one location to another.
* `cat` - Displays the contents of a text file in the terminal.

## Git Commands
* `git init` - Initializes a new Git repository in the current directory.
* `git status` - Displays the state of the working directory and staging area.
* `git add` - Adds file changes from the working directory to the staging area.
* `git commit` - Saves staged changes to the local repository with a descriptive message.
* `git push` - Uploads local repository commits to a remote repository.
* `git pull` - Fetches and merges changes from a remote repository into the current branch.
* `git branch` - Lists, creates, or deletes branches in your repository.
* `git checkout` - Switches between branches or restores working tree files.
